Repositório de dados: Inversor de frequência trifásico para controle em malha aberta de motor de indução trifásico

Esse repositório contém o código desenvolvido para controlar a frequência de uma onda senoidal gera com o módulo MCPWM do microcontrolador ESP32.

Esse projeto foi utilizado para um trabalho de conclusão de curso (TCC) em engenharia elétrica.
